## 🚀 Features (EN)
* **One-Time Access:** Video physically self-destructs after being watched (In-Memory Stream Proxy).
* **Smart i18n:** Auto-detects target's language (EN/PL) instantly on the frontend.
* **FFmpeg Optimizer:** Built-in video compression for low-bandwidth targets (480p, `+faststart`).
* **Zero-Config Tunnel:** Uses Cloudflare Tunnel for instant public exposure without Port Forwarding.
* **Granular Surveillance:** Force camera access on a per-token basis.
* **Portable EXE:** Fully contained in one `.exe` file. It self-heals its folder structure upon launch.

## 🚀 Funkcje (PL)
* **Jednorazowy Dostęp:** Wideo ulega fizycznej autodestrukcji po odtworzeniu.
* **Inteligentne i18n:** Automatycznie wykrywa język (PL/EN) przeglądarki ofiary.
* **FFmpeg Optimizer:** Wbudowana optymalizacja pod słabe łącza internetowe.
* **Tunel Zero-Config:** Wykorzystuje Cloudflare Tunnel do wystawienia w sieci bez konfiguracji routera.
* **Granularna Inwigilacja:** Wymuszanie dostępu do kamery dla konkretnego hasła (Tokenu).
* **Przenośny plik EXE:** Działa z jednego pliku, automatycznie budując swoje foldery na nowym komputerze.

## 🛠️ Build / Kompilacja
Run `1_Kompiluj_System.bat` / Uruchom plik `.bat`, aby zbudować wersję produkcyjną.
